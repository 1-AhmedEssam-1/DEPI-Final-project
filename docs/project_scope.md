# Project scope

Objective: learn to build a reproducible payment-difficulty risk pipeline using Home Credit data, with later modeling, BI, and MLOps work.

Current scope: complete application_train cleaning, feature engineering, and training-only fitted preprocessing; preserve a validation boundary and prepare a clear modeling handoff.

Later: process Kaggle test consistently, inspect and aggregate historical tables, compare integrated features, train and evaluate models, build BI outputs and an inference service, and add monitoring/deployment.

A score derived from model output is a project demonstration, not automatically a validated lending score. The proposal PDF has not been fully reconciled with this scope.
